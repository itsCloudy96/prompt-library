About Cloudy

Cloudy builds free, fast tools for people into AI, AI agents, vibe coding, tech and video games. The Prompt Library is a curated set of 64 original prompts and agent configs you can copy into ChatGPT, Claude, Cursor and other tools.

Looking for the right product instead of a prompt? Try the Cloudy AI Tool Finder — a 30-second quiz and directory of real AI tools.

Want a playable starting point? Cloudy Game Dev Kits are free, MIT-licensed games with a demo, a zip, and a prompt pack.

How we write prompts

  • Every prompt is original Cloudy writing. We do not copy copyrighted prompt packs or vendor system prompts.
  • Each one is written to be useful on its own: a clear job, constraints, and a defined output.
  • They are starting points. Adapt the bracketed placeholders to your project.
